## 🌐 Deployment

### GitHub Pages (Automated via Actions)
This repository includes a GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically builds and deploys the portfolio whenever changes are pushed to `main`.

To enable it on GitHub:
1. Go to your repository on GitHub: `https://github.com/Dynamicsaswat/Saswat_portfolio`
2. Click **Settings** > **Pages** (in the left sidebar).
3. Under **Build and deployment** > **Source**, select **GitHub Actions**.
4. That's it! Every time you push to `main`, GitHub Pages will automatically update your live site.

### Alternative Deployment (Vercel / Netlify)
Because `index.html` is now located at the repository root, you can also connect this repository directly to:
- **Netlify:** Import repository > Build command: *(leave blank)* > Publish directory: `.`
- **Vercel:** Import repository > Framework Preset: `Other` > Root Directory: `./`
